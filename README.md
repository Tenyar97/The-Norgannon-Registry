# The Norgannon Registry
The Norgannan Registry is an open, decentralized protocol for preserving World of Warcraft private server characters independent of any single server operator. Using Ed25519 cryptographic signatures, game servers broadcast signed character snapshots (level, class, gear, progression)to a peer-to-peer network of storage nodes.  Players hold their own keypair through a lightweight companion app, giving them a permanent identity that survives server shutdowns. Any server adopting the protocol can reconstitute a character from the network, meaning years of progress are never lost to a cease-and-desist or a dead host.
